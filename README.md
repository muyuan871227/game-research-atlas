# 游研档案 · Game Research Atlas

一个无需构建即可部署的小游戏研究与原创制作工作台。10 款历史样本、每款 96 个研究字段，支持搜索、字段筛选、三款横向比较、证据审阅、采集任务浏览及 JSON 导出。`#studio` 连接研究依据、原创设计规格、真实 Cocos 参数化试玩与源码交付。

**这是静态研究快照，不是实时榜单，也不是任何游戏、厂商或平台的官方产品或背书。** 更新日期和状态以 `docs/data.json` 为准。

## 本地预览

在本仓库根目录执行：

```sh
python3 -m http.server 8000 --directory docs
```

访问 `http://localhost:8000`。仓库的 `docs/` 可直接作为 GitHub Pages 发布目录；`.nojekyll` 禁用 Jekyll 处理。网页完全静态，不含自动采集后端。已选对比项目保存在浏览器会话中；制作草稿及最近 12 个版本保存在本机 localStorage，可导出或导入 JSON。

## 证据边界

- 历史基线：10 款样本、96 字段，13 条静态验证，0 条基线实机验证；第二轮版本比较为 39 个相同、10 个改动、1 个新增模块。运行时首屏观察与完整玩法闭环分开记录。第三轮六步玩法验收为 0/6，运行资源实际哈希未知，该历史记录保留。
- 第五轮同会话核心玩法闭环已完成 6/6：投放、合成、计分、失败、结算和重开，支持本版本核心循环拆解交付。实际加载主脚本与已分析脚本匹配，但并非完整构建绑定；全商业化报告、其他渠道和另外 9 款深拆尚未完成。
- 静态规则不等于实机行为。渠道构建分别归属，未知、受阻和未验收状态必须保留，不能将其填写成零或“已完成”。
- 公开内容包括研究衍生事实、自行编写的网站与原创原型代码，以及保留许可证的 Cocos 运行库。公开证据另含 8 张指定研究截图和 1 段同会话连续 WebM 录像，位于 `docs/media/g01/`。截图和录像中的游戏、广告等第三方权利仍归各权利人，仅作为机制研究证据；它们不是可再分发的游戏源码或独立素材授权。第三方游戏包、脚本源码或摘录、独立贴图及音频资源、身份凭据与私有报告均不在本仓库内。公开入口与证据摘要用于溯源，不授予再分发原始材料的权利。
- 游戏名称及相关权利属于各自权利人。样本具有选择偏差，不代表完整市场。
- 费用页保留已记录的执行历时和未计量项。执行历时不是人工工时，并行耗时不能直接相加；未知成本不是零成本。第五轮仅通过核心循环范围的实机交付，不能宣称完成全商业化研究报告。

## 更新与验证

维护者先在研究工作区审查新证据、生成经过脱敏的 `site/dist`，再使用标准库导出器按显式清单复制网站文本文件、九个已核验研究媒体文件，以及 SHA-256 清单中的原创 Cocos 构建与源码包。导出器不需要任何个人绝对路径：

```sh
python3 tools/export-public.py --source ../site/dist
python3 tools/export-public.py
node --test tests/*.cjs
```

若本仓库单独克隆，验证命令仍可运行；导出更新需要维护者提供已审核的静态快照目录。脚本会拒绝未经审核的新数据顶层字段、额外文件、私有链接、个人路径及常见凭据模式，并核对数据与链接。媒体只允许 `drop`、`merge`、`score`、`failure`、`settlement`、`restart`、`ready`、`restart-drop` 八张 PNG 和 `continuous.webm`，逐一核验文件头、大小与第五轮描述中的 SHA-256。原始连续录像约 34 MB，未另附游戏资源包。扫描不能替代证据人工复核；发布前仍应审查 diff 和浏览器页面。

## 制作工作台的实际能力

已实现：证据选择与版本溯源、设计参数调整、原创建议规格导出、Cocos Creator 3.8.8 真正可玩的「星屿合成」原型、源码 ZIP、草稿恢复和本地版本管理。主题、标题、步数和目标分实际传入游戏。游戏支持落子、连锁合成、计分、胜负结算和重新开始。

当前是证据辅助的参数化模板；自由文本只进入设计规格，并未调用模型修改代码。通用 AI 生成、云端构建、多用户项目与玩家反馈服务尚未接入。研究样本的 6/6 验收不得自动变成新原型的验收；改动参数后需要单独实测。模型调用与人工总成本未知，不填作零。

构建记录见 `docs/play-build.json`；所有原型文件的字节和哈希见 `docs/play-manifest.json`。`docs/play/` 是原创原型及 Cocos 运行库，`docs/play-source.zip` 提供可编辑项目；许可证保留在两者的 `licenses/` 目录。源码构建需要已安装 Cocos Creator 3.8.8，源码包内附命令说明。

导出器按精确文件允许清单、路径、大小及 SHA-256 校验发布范围，并扫描源码 ZIP 中的文本。研究说明页取代私有报告链接。发布与更新不会改变研究证据的验收状态。
