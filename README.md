# 游研档案 · Game Research Atlas

一个无需构建、无需 npm 的小游戏研究静态网站。10 款历史样本、每款 96 个研究字段，支持搜索、字段筛选、三款横向比较、证据审阅、采集任务浏览及 JSON 导出。

**这是静态研究快照，不是实时榜单，也不是任何游戏、厂商或平台的官方产品或背书。** 更新日期和状态以 `docs/data.json` 为准。

## 本地预览

在本仓库根目录执行：

```sh
python3 -m http.server 8000 --directory docs
```

访问 `http://localhost:8000`。仓库的 `docs/` 可直接作为 GitHub Pages 发布目录；`.nojekyll` 禁用 Jekyll 处理。网页完全静态，不含自动采集后端。已选对比项目仅保存在浏览器会话中。

## 证据边界

- 当前基线：10 款样本、96 字段，13 条静态验证，0 条基线实机验证；第二轮版本比较为 39 个相同、10 个改动、1 个新增模块。运行时首屏观察与完整玩法闭环分开记录。第三轮六步玩法验收为 0/6，运行资源实际哈希未知，完整验收未通过。
- 静态规则不等于实机行为。渠道构建分别归属，未知、受阻和未验收状态必须保留，不能将其填写成零或“已完成”。
- 公开内容仅包括研究衍生事实及自行编写的网站代码。第三方游戏包、脚本源码或摘录、贴图、音频、截图、身份凭据及私有报告均不在本仓库内。公开入口与证据摘要用于溯源，不授予再分发原始材料的权利。
- 游戏名称及相关权利属于各自权利人。样本具有选择偏差，不代表完整市场。
- 费用页保留已记录的执行历时和未计量项。执行历时不是人工工时，并行耗时不能直接相加；未知成本不是零成本。现有观察不足以宣称完成客户级实机交付。

## 更新与验证

维护者先在研究工作区审查新证据、生成经过脱敏的 `site/dist`，再使用标准库导出器显式复制五个已允许文件。导出器不需要任何个人绝对路径：

```sh
python3 tools/export-public.py --source ../site/dist
python3 tools/export-public.py
node --test tests/test-core.cjs
```

若本仓库单独克隆，验证命令仍可运行；导出更新需要维护者提供已审核的静态快照目录。脚本会拒绝未经审核的新数据顶层字段、额外文件、私有链接、个人路径及常见凭据模式，并核对数据与链接。扫描不能替代证据人工复核；发布前仍应审查 diff 和浏览器页面。

文件范围固定为 `docs/{index.html,styles.css,core.js,app.js,data.json,about.html,.nojekyll}`、本 README、`.gitignore`、导出器和测试。研究说明页取代私有报告链接。发布与更新不会改变证据的验收状态。
